# Study Guide: GitHub Foundations (GH-900)

An independent, community-maintained study guide for the Microsoft GitHub Foundations certification. It is aligned to the **January 2026** GH-900 skills measured published by Microsoft Learn.

> This repository is not affiliated with, endorsed by, or an official study guide from Microsoft or GitHub. It contains original explanations and diagrams. The official objectives, learning paths, badge, and external resources remain the authoritative sources.

## Study site

Browse the published guide at [Cloud2BR GH-900 Study Guide](https://cloud2br-msftlearninghub.github.io/GH-900StudyGuide/).
